# 📚 GetBooks - Online Bookstore Frontend

GetBooks is a responsive web application that provides a complete e-commerce bookstore experience. Users can explore curated book categories, search and sort catalog items, manage an interactive shopping cart, and access a client-side admin management dashboard.

🔗 **Live Demo:** [project-get-books.vercel.app](https://project-get-books.vercel.app/)

---

## ✨ Features

### User Experience
* **Catalog & Discovery:** Browse featured releases, best sellers, special offers, and category carousels.
* **Search & Filter:** Search books dynamically by title, author, or description.
* **Sorting:** Sort catalog items alphabetically (A–Z) or by price.
* **Cart Management:** Add items to cart, adjust quantities, view real-time totals, and remove items.
* **Mock Checkout:** Multi-step checkout workflow with customer and shipping details.
* **Contact Form:** Interactive customer inquiry form.

### Admin Experience
* **Role-Based Login:** Access administrative features using the `admin` username.
* **Inventory Control:** Add new book entries or remove existing items dynamically in the UI.

> **Note:** This project is a frontend prototype. Authentication, persistent inventory, and payment processing run via client-side state without a live backend connection.

---

## 🛠️ Tech Stack

* **Frontend:** React 18, JavaScript (ES6+), Babel
* **Styling & UI:** Modern CSS3 (Flexbox/Grid), Font Awesome Icons
* **Data & Media:** Open Library Covers API, Local Asset Storage
* **Deployment:** Vercel
